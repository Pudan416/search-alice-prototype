# Защищённые прототипы

Статические страницы с зашифрованным содержимым. `index.html` открывает презентацию, `game.html` — отдельную игру. Для расшифровки требуется пароль, который не хранится в этой папке. Это экспериментальные прототипы, а не официальный продукт.

Шифрование на стороне браузера ограничивает доступ к содержимому, но безопасность зависит от стойкости выбранного пароля.
